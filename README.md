# Secure-Multi-Site-WAN-using-OSPF-HSRP-and-VLANs
Designed and implemented a secure enterprise multi-site WAN connecting Headquarters and two Branch Offices using Cisco Packet Tracer. The project includes VLAN segmentation, Inter-VLAN Routing, OSPF dynamic routing, HSRP gateway redundancy, ACL-based access control, and WAN connectivity through an ISP cloud to simulate a real enterprise network.
